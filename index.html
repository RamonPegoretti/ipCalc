ipCalc

IPv4 subnet calculator. Type any IP in decimal or binary; results are always in decimal. Starting Python…
Try 192.168.1.45/27 in one box, a mask like /26, or binary like 11000000.10101000.00001010.01100001.
Either box can be decimal or binary.
Accepts 178, 10110010, 192.168.1.1 or a dotted binary address. Binary means exactly 8 zeros/ones per octet.
Subnet counts round up to a power of two: asking for 5 subnets gives 8. Hosts per subnet leaves room for the network and broadcast addresses.
Calculations run in your browser with Python's ipaddress module. Source on GitHub
